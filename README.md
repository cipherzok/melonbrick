# melonbrick

## How to install

1. Download [Mine Blocks.js](https://web.archive.org/web/20260123072208id_/https://mineblocks.com/1/embed/html5//Mine%20Blocks.js?1735551513)
2. Download [Mine-Blocks-32bit.zip](https://web.archive.org/web/20250901222439id_/https://mineblocks.com/1/Mine-Blocks-32bit.zip) and extract it
3. Select `Mine Blocks.js` and `Mine Blocks.exe` from your device [here](https://cipherzok.github.io/melonbrick/)
4. Click the Download button to generate `melonbrick.zip`, then extract it

You need a local server to run the game. [Recommended](https://github.com/cipherzok/standalone-server)

## How to add mods

1. Drag the mod folder (not a `.zip` or `.rar` file) into `./mods`.
2. Add the folder name to `./mods.json`.

[Recommended mods collection](https://github.com/cipherzok/mine-blocks-mods-collection)
